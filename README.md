# MIRC Presentation Site

One configurable website for several conferences (MIRC, PANTAS, and others) and for every year of each.

- `prototype/` is the clickable prototype. Open `prototype/index.html` in a browser. See `prototype/README.md` for how to use it, how the files fit together, how to run the tests, **section 13: how to add a conference in code** (one entry in `prototype/conferences.js`) and **section 14: how to create, change and delete your own conferences on screen** (Conference › My conferences, saved in the browser).
- `MIRC2026_Website_Blueprint.md` is the specification of the real site, written for MIRC 2026 (`MIRC2026_Website_Blueprint.v1-backup.md` is an earlier version).
- `MIRC_Prototype_Flow_Guide.docx` walks through the prototype screens as they were for MIRC 2026; it has not been updated for the Conference box.
